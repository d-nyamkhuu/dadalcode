CONFIRMED FINDINGS

R01 — Use exact comparisons for integer-answer contracts
Integer expectations compare exactly even for float results; medians explicitly retain numeric tolerances through browser JSON. Scalar, nested and browser regressions reject the old float mutant.

R02 — Require nondecreasing factor lists before normalizing outer order
Factor combinations require nondecreasing inner lists while retaining arbitrary outer order; descending, malformed and duplicate candidates are tested.

R03 — One immediate round trip accepts a Codec whose string does not encode the tree
Tree Codec strings decode with fresh class/global state, survive later serialization, reconstruct independent nodes, and reject constant/cache-token shortcuts. Additional judge probes are excluded from learner traces.

R04 — Valid linked lists above 10000 nodes cannot be serialized
Linked-list serialization supports 50000 nodes while retaining cycle/oversize rejection. Both 10001 and 50000-node valid Sort List cases are exercised, including 50000 in Pyodide.

R05 — Distinguish the largest pair sum from the anchored triple sum
3Sum walkthrough arithmetic explicitly includes its anchor.

R06 — Remove impossible overlap-chain example under disjoint input constraints
Insert Interval explains the contiguous overlap block without the impossible disjoint-interval chain scenario.

R07 — Correct the reversed negative-prefix intuition
Maximum Subarray correctly explains that negative prefixes make extending worse than restarting.

R08 — Include the scan of k input heads in the runtime bound
Merge K Sorted Lists includes the initial k-head scan in O(k + N log(k+1)) time.

R09 — Sorted output adds a logarithmic factor to the taught linear traversal
Pacific Atlantic emits deterministic row-major results using a linear membership scan; explanation and exact code notes match O(RC).

R10 — Correctness warning misstates the effect of reversing duplicate pruning
Permutations II explains the wasted partial branches from reversed duplicate pruning without claiming it loses valid completed permutations.
